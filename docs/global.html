WFft

Description:

  • FFT與iFFT

    各函數皆可傳入opt.type指定計算方式: 'dft'(預設)為使用mathjs對任意n點做真實n點DFT(2冪次走Cooley-Tukey、其餘走Chirp-Z)，數據品質最佳但非2冪次時較慢； 'pow2'為先補零至2冪次(最少4點)再使用ml-fft之radix-2 FFT，速度極快適合前端即時繪圖，但輸出點數為補零後之2冪次，且非2冪次輸入時頻率bin為DTFT插值而非真實n點DFT。

    輸入參數檢測：各函數之輸入參數皆於入口先檢測(dft與pow2兩路徑一致)，無效時同步throw Error，訊息格式為invalid <名稱>: must be <種類描述>且不帶輸入值。 數據陣列(含二維矩陣)之元素種類為有效數字：有限數字或數字字串(轉換為數字後才運算)，非數字(含'-'、'NP'、''、null、布林、NaN、Infinity)一律無效，不視為0； dt、hzStart、hzEnd為有效數字(dt須為正數，頻率須為非負數)；opt.useOneTurn為布林(只收true或false)，opt.type為列舉字串('dft'或'pow2')，opt為一般物件， opt之鍵為undefined或null取預設，給了而無效即throw Error，不靜默改用預設。詳見各函數說明。

    最小輸入長度：輸入長度不足以產生有意義之頻譜或濾波結果時，入口即throw Error(invalid arr: must be an array with at least N elements；二維為invalid mat: must be an array with at least N rows或invalid mat[0]: must be an array with at least N columns)，dft與pow2一致，以輸入長度判定而非補零後點數。 spectrum1d至少4點、spectrum2d列數與行數各至少4點(須含非直流頻率點)；filter1d至少2點、filter2d列數與行數各至少2點(須含非直流bin)；fft1d、ifft1d、fft2d、ifft2d長度1為正確之1點DFT，不拒絕。

FFT與iFFT

各函數皆可傳入opt.type指定計算方式: 'dft'(預設)為使用mathjs對任意n點做真實n點DFT(2冪次走Cooley-Tukey、其餘走Chirp-Z)，數據品質最佳但非2冪次時較慢； 'pow2'為先補零至2冪次(最少4點)再使用ml-fft之radix-2 FFT，速度極快適合前端即時繪圖，但輸出點數為補零後之2冪次，且非2冪次輸入時頻率bin為DTFT插值而非真實n點DFT。

輸入參數檢測：各函數之輸入參數皆於入口先檢測(dft與pow2兩路徑一致)，無效時同步throw Error，訊息格式為invalid <名稱>: must be <種類描述>且不帶輸入值。 數據陣列(含二維矩陣)之元素種類為有效數字：有限數字或數字字串(轉換為數字後才運算)，非數字(含'-'、'NP'、''、null、布林、NaN、Infinity)一律無效，不視為0； dt、hzStart、hzEnd為有效數字(dt須為正數，頻率須為非負數)；opt.useOneTurn為布林(只收true或false)，opt.type為列舉字串('dft'或'pow2')，opt為一般物件， opt之鍵為undefined或null取預設，給了而無效即throw Error，不靜默改用預設。詳見各函數說明。

最小輸入長度：輸入長度不足以產生有意義之頻譜或濾波結果時，入口即throw Error(invalid arr: must be an array with at least N elements；二維為invalid mat: must be an array with at least N rows或invalid mat[0]: must be an array with at least N columns)，dft與pow2一致，以輸入長度判定而非補零後點數。 spectrum1d至少4點、spectrum2d列數與行數各至少4點(須含非直流頻率點)；filter1d至少2點、filter2d列數與行數各至少2點(須含非直流bin)；fft1d、ifft1d、fft2d、ifft2d長度1為正確之1點DFT，不拒絕。

true=各軸視為一個完整週期(頭尾重複)，週期(len-1)dt；false=標準DFT，週期lendt。種類為布林(只收true或false)，undefined或null取預設，給了而非布林(如'n'、'false'、0、1)throw Error(invalid opt.useOneTurn: must be a boolean)，不以真值判定
type String <optional>
 'dft'

輸入計算方式字串，種類為列舉字串('dft'或'pow2')，undefined或null取預設，給了而不在列舉內throw Error(invalid opt.type: must be one of 'dft', 'pow2')，不靜默改用預設。'dft'為使用mathjs對任意m×n點做真實m×n點DFT(各軸2冪次走Cooley-Tukey、其餘走Chirp-Z)，數據品質最佳但非2冪次時較慢；'pow2'為兩軸各自先補零至2冪次(最少4點)再使用ml-fft之radix-2 FFT，速度極快適合前端即時繪圖，但頻譜尺寸與各軸頻率解析度df係以補零後之2冪次點數計算，預設'dft'
